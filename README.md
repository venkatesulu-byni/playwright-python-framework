# Tutorial: Web Testing with Playwright in Python

## Configuration
    pytest
    pytest-playwright

### Run below command in Pycharm terminal to install browser binaries:
    # To Install default browsers 
    playwright install
    
    # To install individual browsers
    playwright install chromium
    playwright install msedge
    playwright install firefox
    playwright install webkit

    # Run below to get the list of installed browsers by Playwright
    playwright install --list
